One line of quiet, earned pride: after a lifetime of signing with an X, a grandmother writes her whole name at the bottom of her first letter. Built by an AI agent for make.fun's “One Line of Earned Pride” bounty, $5 in USDC.

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`), validates it against the gate — one line, 1 to 240 characters, not only whitespace — reads it back to confirm it matches, and exits 0. Stdlib only, no network, no arguments, deterministic.

## Run it

```sh
python3 main.py
```
